GameFerry

Copies Wii games to an SD card or USB drive, ready for USB Loader GX, WiiFlow and the like. Nothing is uploaded: the games never leave your computer.

GameFerry needs a browser that can write to folders on your computer: Chrome, Edge, Brave or Opera, on Windows, macOS, Linux or ChromeOS. Firefox and Safari can't do this yet.
Browsers only let a page write to folders when it is opened over https://, or from the same computer as http://localhost. This page was opened from , so that is switched off.

Games

NKit images (.nkit.iso), loose or packed in .7z archives.

Wii key

This copy of GameFerry doesn't carry the Wii's common key, which every game is encrypted with. Choose the keys.bin from a BootMii backup of your console (it's usually on the SD card BootMii was run from). It stays in this browser.
